Reading the matrix

Each row is one direction. The two rows of a clip are scored independently, because two people in the same conversation do not have the same information about it: the senior colleague giving unsolicited advice reads the exchange as warm (V +1) while the junior reads it as intrusive (V −1).

A hatched cell is an annotation not yet public. Hover any cell for the evidence timestamp and the annotator’s rationale.

These samples are generated from data/*.jsonl by scripts/export_site_data.py. Adding a clip to the released files adds it here.
